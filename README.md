# HYBRID ATHLETE — Training OS

A responsive gym + calisthenics workout planner with a weekly schedule, exercise checklists, training preferences, and browser-local progress.

## Live site
https://ninja94650.github.io/hybrid-athlete/

## Deploy
The GitHub Actions workflow in `.github/workflows/pages.yml` deploys this repository to GitHub Pages when changes are pushed to `main`. In repository **Settings → Pages**, ensure the build/deployment source is **GitHub Actions** if Pages is not enabled automatically.

## Included
- Monday–Sunday gym + calisthenics training split
- Extra focus on chest, shoulders, arms, back and core
- Gymnastics foundations: scapular push-ups/pull-ups, hollow and arch holds, support holds, pike push-ups and tuck L-sit progressions
- Per-exercise completion tracking and session progress
- Adjustable level, goal, equipment access and weekly frequency
- Browser-local persistence via localStorage

## Limitations
This is a front-end prototype. Progress is stored in the current browser profile and is not synced between devices. There is no account system, cloud database, notification service, or live AI coach.

## Safety
Warm up, use controlled progressions, and stop movements that cause sharp or worsening pain. This planner is general fitness guidance, not medical advice.
